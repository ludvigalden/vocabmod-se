# Security

vocabmod-se is a terminology corpus and a command-line tool that reads
it from local files. The tool opens no network connections and runs no
service.

Report a vulnerability in the tool, or a file in the corpus that carries
material it must not carry (personal data, licensed text, credentials),
by email to <vocabmod-se@ludvigalden.com>, not in a public issue. Include
the commit, the path, and how to reproduce it.

Reports are acknowledged within seven days. A confirmed problem is
fixed on `main`, and the reporter is credited unless they ask not to be.
