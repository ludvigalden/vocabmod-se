# Vendored fonts

The report templates under `pkg/typ/` set text in Source Sans 3 (body)
and Source Code Pro (headings, code, and identifiers). Both families are
vendored here as variable TTFs under the SIL Open Font License, version
1.1; the license beside each family covers it and is reproduced
unchanged.

Compile with `typst compile --root <repo> --font-path <repo>/pkg/typ/assets/fonts`.
